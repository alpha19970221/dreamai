# 设计文档：「继续追问」聊天界面

**日期：** 2026-04-06
**范围：** `prototype/index.html` — `#step-interpret` 视图

---

## 功能概述

在"指引：高维的游戏"界面，用户点击"我想继续追问"后，原地展开一个仿 WeChat/WhatsApp 风格的对话区域，允许用户与祭司（软件）进行多轮模拟对话，"生成梦境图"按钮始终固定在底部。

---

## 布局结构

```
┌──────────────────────────┐
│ 指引：高维的游戏           │  标题
│ [解读文字]                │  interpret-content（压缩，可滚动）
│ ┌──────────────────────┐ │
│ │ ✦ 祭司：...          │ │  左气泡（软件）
│ │         你：...  ██ │ │  右气泡（用户）
│ │ [正在感应中 ···]      │ │  typing 动效
│ └──────────────────────┘ │  聊天区（240px，overflow-y: auto）
│ [输入框            ][发送] │  输入行
│ [       生成梦境图       ] │  底部固定按钮
└──────────────────────────┘
```

---

## 交互流程

1. 点击"我想继续追问" → 按钮淡出消失（`display: none`）
2. `#chat-area` 以 `slideUpFadeIn` 动画展开
3. 聊天区顶部预置一条祭司开场白
4. 用户输入后点击发送（或回车）：
   - 用户气泡立即显示，输入框清空
   - 立即出现 typing 指示器（三点跳动）
   - 1.2s 后 typing 消失，随机回复气泡出现
   - 聊天区自动滚动到最新消息
5. "生成梦境图"始终可点击，进入图像生成流程

## 样式规范

| 元素 | 样式 |
|------|------|
| 用户气泡 | 右对齐，`rgba(139, 92, 246, 0.4)`，圆角 `18px 18px 4px 18px` |
| 祭司气泡 | 左对齐，`rgba(255,255,255,0.08)`，`border: 1px solid rgba(255,255,255,0.1)`，圆角 `18px 18px 18px 4px` |
| 输入框 | 毛玻璃背景，单行，`border: 1px solid rgba(139,92,246,0.4)` |
| 发送按钮 | 小尺寸 `.btn-manifest` 变体，紫色 |
| Typing | 三个圆点，`bounce` 动画，错位延迟 |

## 模拟回复池（8条）

1. 你所追问的，正是潜意识试图让你看见的裂缝。继续说，它在倾听。
2. 这个问题本身，就是一把打开内室的钥匙。你感受到了什么？
3. 梦境的语言从不撒谎。那个画面背后，藏着你尚未命名的情绪。
4. 高维视角下，所有的困惑都是方向。你内心真正想放下的是什么？
5. 宇宙用这个梦回应了你的某个请求。那个请求，你还记得吗？
6. 意识是一面镜子，梦是镜子背后的光。你看到了自己的哪个侧面？
7. 不必急于解读，有时候只是带着这个意象生活几天，答案会自己浮现。
8. 你的追问本身就是疗愈的一部分。继续，祭司在此聆听。

## 技术约束

- 单文件开发，所有 CSS/JS 内联
- 新 CSS 追加在 `<style>` 末尾
- 新 JS 追加在 `<script>` 末尾，不污染全局变量
- 不破坏 `#app-container` 的 `position: relative` / `overflow: hidden`
- 聊天区高度固定 `240px`，不撑破布局
