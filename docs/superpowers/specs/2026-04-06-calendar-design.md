# 梦境封印录 · 日历视图 设计文档

**日期**: 2026-04-06
**状态**: 已确认，待实现

---

## 概述

将「梦境封印录」（`step-archive`）的视图从静态卡片列表改为全屏月历，用户可通过点击日期查看当天记录的梦境，替代原有的线性列表浏览方式。

---

## 设计决策

| 决策项 | 选择 | 说明 |
|--------|------|------|
| 布局方案 | 全屏日历替换列表 | 移除原卡片列表，日历占满页面主体 |
| 日期标记风格 | 封印符文 ◈ | 有梦日期背后浮现半透明 ◈，呼应"封印录"主题 |
| 点击交互 | 底部抽屉 | 日历保持可见，卡片从底部滑入 |
| 数据存储 | JS 硬编码数组 | 原型阶段，`const dreams = [...]` 存于脚本末尾 |

现有详情页保持不变，返回按钮文案已是「⟵ 返回封印录」，复用即可。

## 交互流程

```
进入封印录（step-archive）
  → 渲染当月日历，根据 dreams 数组标记有梦日期（◈ 符文）
  → 点击有梦日期
      → 底部抽屉滑入（translateY 动画，300ms ease）
      → 显示该日期的梦境摘要
  → 点击无梦日期 / 再次点击同一日期
      → 抽屉收起
  → 点击「深入凝视」
      → goToStep('step-archive', 'step-archived-detail')
  → 详情页左上角「⟵ 返回封印录」
      → goToStep('step-archived-detail', 'step-archive')
  → 点击「‹ / ›」切换月份
      → 重新渲染日历，抽屉收起
```

## 视觉规范

- **背景色**: `#050a15`（与全局保持一致）
- **符文颜色**: `rgba(139, 92, 246, 0.22)`（半透明紫，叠加在日期数字后方）
- **选中日期**: `background: rgba(139, 92, 246, 0.45)`，圆形，带光晕
- **今日**: 细边框 `border: 1px solid rgba(139, 92, 246, 0.4)`
- **底部抽屉背景**: `linear-gradient(160deg, rgba(22,16,42,0.98), rgba(8,8,20,0.99))`，`backdrop-filter: blur(20px)`
- **抽屉顶部边线**: `border-top: 1px solid rgba(139, 92, 246, 0.25)`
- **「深入凝视」按钮**: 继承现有 `.btn-manifest` 样式变体（毛玻璃+紫色描边）
- **字体**: 标题用 `Noto Serif SC`，正文/数字用 `Inter`

## 实现范围

**包含：**
- 替换 `step-archive` 页面内容为月历
- 新增 `dreams` 数组数据
- 月份切换（前/后月）
- 日期点击 → 底部抽屉动画
- 抽屉内容渲染（标题、标签、预览、按钮）
- 点击「深入凝视」跳转现有详情页

**不包含（本次范围外）：**
- 详情页内容动态化（仍保持硬编码）
- localStorage 持久化
- 多条梦境同一天的场景（当前数据无此情况）
- 年视图 / 搜索功能
