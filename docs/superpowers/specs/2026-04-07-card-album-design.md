# 回忆卡册 · 设计文档

**日期**: 2026-04-07
**状态**: 已确认，待实现

---

## 概述

在「梦境回忆录」（`step-archive`）页面内新增标签切换栏，支持在现有日历视图与新增的卡册视图之间切换。卡册视图以单列列表形式展示所有梦境，每条梦境一张卡片，点击卡片跳转详情页。

---

## 设计决策

| 决策项 | 选择 | 说明 |
|--------|------|------|
| 入口 | 页面内 tab 切换 | 日历与卡册共用 `step-archive`，顶部标签切换，无需新增路由 |
| 卡牌布局 | 单列带预览文 | ◈ 符文 + 日期 + 标题 + 预览文，信息层次清晰 |
| 排序 | 日期降序 | 最新梦境显示在最上方 |
| 点击行为 | 跳转详情页 | `goToStep('step-archive', 'step-archived-detail')` |
| 状态管理 | JS 变量 `calView` | `'calendar'` 或 `'cards'`，控制两种视图的显示/隐藏 |

## 交互流程

```
进入梦境回忆录（step-archive）
  → 默认显示日历视图（tab: 📅 日历 高亮）
  → 点击「🃏 卡册」tab
      → calView = 'cards'
      → 隐藏：月份导航、日历格、日历计数栏、空状态、底部抽屉
      → 显示：卡册列表容器（按日期降序渲染 dreams 数组）
  → 点击「📅 日历」tab
      → calView = 'calendar'
      → 恢复日历视图，隐藏卡册列表
  → 点击某张梦境卡片
      → goToStep('step-archive', 'step-archived-detail')
```

## 实现范围

**包含：**
- `step-archive` 顶部新增 tab 切换栏（HTML + CSS）
- 卡册列表容器（HTML 骨架）
- `switchCalView(view)` JS 函数：切换 `calView` 状态，控制显示/隐藏
- `renderCards()` JS 函数：按日期降序渲染 `dreams` 数组到卡册列表
- 点击卡片跳转 `step-archived-detail`
- tab 切换时收起底部抽屉（`hideCalBottomSheet()`）

**不包含（本次范围外）：**
- 详情页内容动态化（仍保持硬编码）
- 卡册内搜索/筛选功能
- 动画过渡（tab 切换为即时切换）
